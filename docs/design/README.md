# Design 2.0 board

`design-2-board.html` is the approved Design 2.0 board (P7.7, 28 Oct 2026): working prototypes of the rider app, brand portal and staff portal in the new look, plus the system underneath (colour, type, parts, motion, pictures). It is the reference for steps P7.7.2–P7.7.5.

- Published for Prateek as the private page "RECALL Design 2.0".
- To open it locally, put it next to an `img/` folder holding the files from `packages/design/brand/photos/` and open it in a browser.
- The real values live in `packages/design` (tokens and `components.css`); where the board and the code differ, the code wins.
