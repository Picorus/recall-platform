# RECALL logo and app icons

The logo is the brand book's (the "RECALL" design system, section Logo). Use these files as given; never retype the wordmark in a font, recolour, stretch or redraw the symbol.

## Logo (`logo/`)

| Use | File |
|---|---|
| Default, on `paper` or light photos | `recall-lockup-horizontal-light.svg` (volt + midnight) |
| On `midnight`, screens, dark photos | `recall-lockup-horizontal-dark.svg` (volt + paper) |
| On `volt` | `recall-lockup-horizontal-midnight.svg` (all midnight) |
| Square spaces, posters | `recall-lockup-stacked-light.svg` / `-dark.svg` |
| Small spaces where RECALL is already named | `recall-symbol-volt.svg` / `-midnight.svg` / `-paper.svg` |
| Wordmark only (legal lines, footers) | `recall-wordmark-midnight.svg` / `-paper.svg` |
| App icon (source of every icon below) | `recall-app-icon.svg` (volt symbol on a midnight rounded square) |

Clear space equals the cap height on every side. Minimum 120 px wide on screen (symbol alone 24 px tall).

## App icons (`icons/`, generated by `pnpm --filter @recall/design build`)

| Where | File |
|---|---|
| Portals: browser tab | `web/favicon.svg`, `web/favicon-32.png` |
| Portals: iPhone home screen | `web/apple-touch-icon.png` (180 px, square; iOS rounds it) |
| Portals: installed web app (manifest) | `web/icon-192.png`, `web/icon-512.png`, `web/icon-maskable-512.png` (purpose "maskable") |
| Rider app (Expo) `icon` | `app/icon-1024.png` |
| Rider app and screen player: Android adaptive icon | foreground `android/adaptive-foreground-1024.png`, background colour `midnight` #0A0E17 |
| Play Store listing | `android/play-store-512.png` |

The square and adaptive versions are made from `recall-app-icon.svg` by moving or scaling the same three shapes (`src/icons.ts`); nothing is redrawn. Change the icon there and rebuild.
